# Upstream ROS 2 launch file snapshots

This directory includes three **unaltered snapshots from the user's installed copy** of [`legalaspro/so101-ros-physical-ai`](https://github.com/legalaspro/so101-ros-physical-ai). They are third-party reference code, **not the author's original implementation**:

- `so101_bringup/recording_session.launch.py`
- `so101_bringup/inference.launch.py`
- `so101_inference/async_infer.launch.py`

These files are for auditing compatibility with the captured configs and command lines. Prefer installing the upstream dependency at a pinned commit instead of using these files as a replacement package. Keep the upstream license and copyright notices, and before a public release confirm that redistribution complies with the applicable license and include its LICENSE/NOTICE as needed. Exact upstream commit was not provided in the upload.
