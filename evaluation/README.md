# Evaluation protocol

Videos have been recorded for all three initial models under normal and low light. Videos document physical tests but alone do not establish success rates.

For a controlled comparison, fix starting positions, target geometry, lighting definition, camera calibration, runtime configuration, and maximum trial duration; define a success criterion in advance. Record **every** attempted trial, not only successes. Use `trials.csv` to record newly scored data.

Suggested measures: task success rate by position and lighting, completion time, inference latency, intervention counts, and failure types (missed grasp, out-of-workspace motion, failed placement, etc.). Separate qualitative observations from measured results.
