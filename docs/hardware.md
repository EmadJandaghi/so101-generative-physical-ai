# Documented hardware and runtime

- SO-101 leader and follower arms
- Raspberry Pi 5 (8 GB)
- Wrist USB camera and Logitech C920 overhead camera
- Ubuntu Server 24.04, ROS 2 Jazzy
- Six joint state/action channels, two camera streams
- Unity GPU cluster for training and Vast.ai GPU for some inference runs

Do not assume USB device paths, camera calibration, motor configuration, or network endpoints are transferable to other machines. Publish verified configuration examples only after inspecting the live files.
