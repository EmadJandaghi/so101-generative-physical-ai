# Data collection

111 manual SO-101 pick-and-place demonstrations using two cameras, six joint states/actions, and nine cube starting positions. Reference dataset:
https://huggingface.co/datasets/Emadodin/so101_pickplace_manual_extra_v1

The upstream recording and LeRobot conversion stack is described at https://github.com/legalaspro/so101-ros-physical-ai. The actual local config and data-conversion commands will be added once recovered and validated.
