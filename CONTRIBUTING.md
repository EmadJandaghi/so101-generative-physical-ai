# Contributing to the SO-101 experiments

Please retain proper attribution and identify the upstream provenance of any adapted source code. For experiments, record the dataset revision, code revision, environment, training command, hardware, number of trials, evaluation criteria, and failure cases. New architecture claims and quantitative performance comparisons need supporting evidence.

Do not commit personal secrets, course-only PDFs, model checkpoints, original unlicensed third-party materials, or unreviewed network endpoints. Any code that issues real robot commands must be tested safely with physical supervision and documented limits.
